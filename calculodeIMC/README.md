# Calculadora de IMC

Sistema que calcula o Índice de Massa Corporal (IMC) do usuário
e informa sua classificação de peso com base em tabela oficial.

## Funcionalidades

- Recebe peso e altura fornecidos pelo usuário
- Calcula o IMC automaticamente
- Compara o resultado com a tabela de classificação oficial
- Informa se o usuário está no peso ideal, acima do peso ou com obesidade

## Como usar

1. Execute o arquivo no VS Code
2. Informe seu peso quando solicitado
3. Informe sua altura quando solicitado
4. O sistema exibe o IMC calculado e a classificação

## Tecnologias

- Java
- Scanner
- VS Code
