# Sistema de Recepção Hospitalar

Sistema de triagem digital para direcionar pacientes ao atendimento
correto de forma prática e objetiva.

## Funcionalidades

- Exibe menu de opções numéricas ao paciente
- Direciona para o setor de atendimento correto conforme a escolha
- Mensagens exibidas em monitor na recepção

## Como usar

1. Execute o arquivo no VS Code
2. O sistema exibe as opções de atendimento disponíveis
3. O paciente seleciona o número correspondente à sua necessidade
4. O sistema direciona para o atendimento correto

## Tecnologias

- Java
- VS Code

## Observações

- Aplicação roda no terminal
