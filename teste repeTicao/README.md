# Protótipos de Caixa de Compras

Dois protótipos de sistema de caixa desenvolvidos como exercício prático,
ambos com potencial de evolução para aplicações mais completas.

## Programas

### CaixaRapido (mais completo)
- Solicita nome do item, valor e quantidade
- Calcula o valor total da compra automaticamente

### Versão simples
- Solicita dados básicos da compra
- Calcula o total ao final

## Tecnologias

- Java
- Scanner
- VS Code

## Observações

- Aplicações rodam no terminal
- Projetos em fase de protótipo, com espaço para melhorias futuras
- Projeto desenvolvido na disciplina de Algoritmos e Programação
