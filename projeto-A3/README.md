# Sistema de Folha de Pagamento

Sistema desenvolvido para otimizar o trabalho de equipes de RH, 
automatizando o cálculo e a geração da folha de pagamento dos funcionários.

## Funcionalidades

- Cadastro de funcionários com nome e matrícula
- Geração automática de matrícula (evita duplicidade)
- Cálculo de salário fixo + rendimentos extras
- Cálculo de comissão e produção por categoria de funcionário
- Geração da folha de pagamento com todas as informações

## Como usar

1. Execute o arquivo Main.java no VS Code
2. Informe o nome do funcionário quando solicitado
3. Informe os rendimentos extras, se houver
4. O sistema calcula e exibe a folha de pagamento

## Tecnologias

- Java
- ArrayList
- Scanner
- VS Code

## Observações

- Aplicação roda no terminal
- Dados ficam em memória durante a execução (sem banco de dados)
- Projeto desenvolvido na disciplina de Algoritmos e Programação
